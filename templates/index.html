About This Project

This project is a beginner-friendly AI programming chatbot built using Python, Flask, SQLite and Ollama. It can answer programming questions, generate code, explain code and help debug programming errors.

Technologies: Python, Flask, HTML, Bootstrap, SQLite, JSON, Ollama and Llama 3.2.
